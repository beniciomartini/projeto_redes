Projeto 1 — Identificador de Protocolos de Rede

Projeto desenvolvido para a disciplina de Redes de Computadores.

Objetivo

O programa simula a análise de pacotes recebidos por um computador e identifica o protocolo utilizado.

Protocolos

* 1 — TCP
* 2 — UDP
* 3 — ICMP
* Outro número — Protocolo desconhecido

## Linguagem

O projeto foi desenvolvido em C, utilizando as estruturas básicas solicitadas na atividade:

* if
* else
* for
* printf()
* scanf()

Funcionamento

O usuário informa a quantidade de pacotes que deseja analisar. Depois, o programa solicita o protocolo de cada pacote e informa qual protocolo foi identificado.
